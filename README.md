# 回转走线 · AI 轨迹优化

滑雪回转/大回转比赛的 AI 对手不再沿旗门中心连线硬折，而是把整条赛道的滑行线建模为
**受物理约束的轨迹优化问题**：由优化器自行决定每道门提前多少米起弧、从门线上方（高线）
还是下方（低线）绕过、贴杆还是留裕度。不同性格的对手风险偏好不同，冰面/雪包会触发比赛中的
临时修正，冒险型修正失败会真实 DNF。

## 物理模型（`src/engine/physics.ts`）

- 走线：每门两个决策变量（沿门线位置 `along`、过门上下偏移 `normal`，normal 限幅 ±1.8m），
  带张力的 Cardinal 样条（tension 0.5，抑制门线附近过冲/回环）串成光滑线，按 1.2–2.2m
  弧长重采样，数值差分求曲率 κ
- 弯中速度硬约束：`v²κ ≤ min(μ·g·cosθ, g·cosθ·tan(立刃角))`，μ 由雪况、冰面病害、性格共同决定
- 转弯角速度约束：`v·κ ≤ ω_max`（人体旋转能力），对所有走线一视同仁
- 纵向：重力加速度 − 气动/滚阻 − 弯侧切刮雪损耗，前向积分
- 后向制动扫描：`v(s) ≤ √(v(s+ds)² + 2·制动减速度·ds)`，刹不住的走线不可行
- 总用时 = ∫ ds/v；漏门（门线首次穿越点沿门线坐标超出门杆）、几何回环、越界均以 500s 重罚，
  使可行性压过任何时间收益；基线与优化线用完全相同的样条与积分，时间差只反映优化决策

## 优化方法（`src/engine/optimizer.ts`）

**多起点 + 多分辨率坐标下降**（Gauss-Seidel 贪心 + 步长衰减 + 正反扫），确定性、无需求导：

1. 三个起点（贴内杆 / 门心 / 高线）各分 1/3 预算独立下降，全局取代价最低者，避免冰面赛道的局部最优
2. 每个起点内按粗（2.2m、步长 2m）→ 中（1.8m）→ 细（1.4m）三分辨率收敛
3. 绝对时间截止保证任何赛道都在预算内返回，终评用 1.2m 标准分辨率

带张力样条的光滑性使相邻门变量天然耦合，"提前起弧、走高线"作为物理代价下的最优解自行涌现，
而不是手写规则。

## 风险偏好如何体现

不是速度加成，而是一组进入优化器可行域的物理参数：

| | 稳健 · 林岚 | 均衡 · 陈溯 | 冒险 · 雷克 |
| --- | --- | --- | --- |
| 最大立刃角 | 62° | 68° | 73° |
| 基础握力 μ | 0.62 | 0.70 | 0.78 |
| 冰面握力保留 | 0.85 | 0.70 | 0.50 |
| 走廊/过门裕度 | 1.6m / 0.55m | 1.0m / 0.35m | 0.35m / 0.12m |

冒险型走线更直更短、贴杆、极速高，但冰面可用握力储备低；比赛模拟中若 `v²κ/g > μ_冰面`
即侧滑 DNF。模拟还含由种子确定性生成的发挥波动（冒险型 ±3%，稳健型 ±0.8%）。

## 临时修正（`src/engine/race.ts`）

每个时间步沿弧长前瞻 0.5–14m 扫描病害：

- **雪包**：提前制动到雪包限速
- **冰面**：按冰面实际握力与当地曲率反推安全速度 `vSafe=√(μ冰·g·0.9/κ)`，提前收速；
  同时沿最近门的**门线方向**横移避让（沿门线平移不改变门线法向坐标，几何上不会推过门线端点），
  横移量被沿途每道门的门杆余量与走廊边界显式夹取，冒险型只做小幅直线修正

漏门判定与优化评价同构：取门线法向坐标的首次穿越点检查门杆间距，并拒绝门线附近的几何回环。

## 硬指标验收（`src/engine/optimizer.test.ts`，vitest）

1. **快 5% 以上且不漏门**：5 赛道 × 3 性格共 15 个组合，实测提升 **23.9–38.6%**，
   全部 `allGatesCleared=true`、零走廊越界（含冰面夜场这类紧约束赛道）
2. **60 门 ≤ 3 秒**：实测单对手 2.1–2.4s（含三起点下降与终评），浏览器 Worker 内约 2.2s

另有 FIS 规格区间、立刃/极速/握力物理上限、门心基线物理对照、总转向量守恒、
风险偏好走线差异、冰面/雪包修正事件、公平基线等共 19 个测试。
浏览器端用 CDP 脚本（`scripts/cdp-smoke.mjs`、`cdp-pages.mjs`）做真实 Worker 与四页面冒烟。

## 赛道规格（确定性生成，同 seed 可复现）

- 回转 SL：门距（欧氏）7–13m、门宽 4–6m、相邻门横向偏移 4–9m、55–64 门
- 大回转 GS：门距 13–22m、门宽 4–8m、横向偏移 6–14m、48–60 门
- 门位生成对欧氏间距与横向位移做硬约束（含边界反射），门序沿坡单调
